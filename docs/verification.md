# 验证说明

基础自动检查：

```sh
go test -mod=vendor ./...
go vet -mod=vendor ./...
```

单元与集成模拟覆盖微信登录/媒体/引用、会话隔离、消息去重、模型设置、文件上传授权、ZIP 路径、进度租约、运行中追加、结果打包/回传收据、账号导入和运维报表。

测试服务使用回环监听和合成凭据，不访问真实微信联系人，不需要提供 Codex Key。跨平台构建不代表所有平台均已完成真实服务验收；主部署组合是 Windows Relay 与 Linux Worker。Windows 的账号重载与系统维护适配器不能直接在 Linux 上使用。

发布快照基于现有已部署实现，整理了模块路径、目录、通用配置、许可、文档和构建入口；另修复回传循环退出时等待后台文字协程，并让相应测试在清理临时存储前等待退出。现有服务器没有因本次整理而重启。临时探测命令、账号数据、截图、服务器地址、历史任务与编译产物没有收录。
