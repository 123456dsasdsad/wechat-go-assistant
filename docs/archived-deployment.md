# Archived relay deployment

This source snapshot preserves the changes used by the `2026.10.16-ha1` relay deployment before its retirement on 2026-10-25. It includes the relay, workers, reusable configuration examples, and snapshot/restore tools.

Production credentials, account uploads, login state, private configuration, task history, and runtime files are excluded from this repository. A source checkout alone does not restore production identity or data.
