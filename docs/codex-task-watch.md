# 在微信查看桌面 Codex 任务

为外部任务新建独立的微信编号会话，使用 `cmd/threadwatch` 把指定任务的公开进度同步到阿里云中继。监看不创建校园 AI 任务，不消耗额外模型 token。

在进度会话发送“任务状态”“查看进度”或“任务列表”，可获取最新说明与 24 小时有效的进度链接。网页每 5 秒刷新。微信工作台也会显示绑定的任务。修改原任务要求仍在原 Codex 会话进行；切换普通微信会话可继续使用 AI。

本地运行：`go run ./cmd/threadwatch -config <私有配置文件>`。配置字段为 `rollout`、`thread`、`title`、`conversation`、`ssh_target`、`remote_config`。指定文件必须属于指定线程。私有配置不得提交；SSH 使用既有配置和严格主机密钥校验，中继 API 密钥只在服务器读取。支持 `-once` 单次验收。

同步只提取带 commentary/final 阶段的助手消息与任务开始、结束事件，不同步用户输入、工具参数、工具输出或推理内容。同步间隔 20 秒，断网自动重试，源文件未写完的最后一行留待下一轮读取。中继保存绑定和最近 40 条进度，拒绝旧序号、冲突更新和跨任务重绑。

同步依赖运行桌面 Codex 的电脑。超过 90 秒没有心跳时页面和微信回复标注“同步已中断”，同时展示最后进度与同步时间。Codex 本轮回复完成不代表独立的远程训练已经完成，训练状态以原任务最新说明为准。心跳不会主动重复发送微信消息。

## 独立训练队列

原 Codex 启动独立训练队列后，可交接为校园端 `cmd/queuewatch` 采集器。它只读取调度器的 `status/experiment_queue.json` 与各实验的 `live_progress.json`，显示实际作业数、轮次、优化步数、loss 及各记录更新时间，不启动、停止或修改实验。运行所需的 relay 地址和密钥路径从校园 worker 私有配置读取。

交接时停止桌面采集器，保持同一个微信会话与任务绑定。服务器每30秒同步训练状态，进度页标明服务器来源，此模式无需本机电脑在线。采集器无法读取队列或同步失败时不覆盖最后记录；90秒后显示同步中断。
