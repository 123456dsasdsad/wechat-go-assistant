# 手机指令

这些指令由 Go 入口直接处理，不用 AI 修改配置。每条微信消息只放一条控制指令。

| 目的 | 示例 |
| --- | --- |
| 查看模型 | `模型列表`、`当前设置` |
| 默认模型 | `默认模型 2` 或 `默认模型 gpt-6-sol` |
| 推理强度 | `推理强度 low` |
| 临时模型 | `使用 gpt-6-sol：读取附件并总结` |
| 新建会话 | `新建会话 项目分析` |
| 选择会话 | `会话列表` 后回复 `1`，或 `继续会话 1` |
| 查看会话 | `当前会话` |
| 会话改名 | `重命名会话 1 项目分析`、`会话命名 论文修改` |
| 运行中追加 | `补充：把结果保存为 CSV` |
| 查看待回答问题 | `待回答`、`问题列表` |
| 回答 AI 提问 | 引用机器人发来的问题，回复 `2`、选项文字或自定义内容 |
| 无法引用时回答 | `回答 <问题编号> <答案>` |
| 查询任务 | `任务状态`、`任务列表` |
| 文件上传 | `上传文件`、`文件列表`、`文件帮助` |
| 处理文件 | `分析最新文件：总结内容`、`分析文件 <文件ID>：处理要求` |
| 粘贴聊天 | `转发内容`、`转发消息`、`聊天转发`、`粘贴聊天` |
| 明确补发结果 | `回传任务 <8位任务编号>` |
| 账号导入 | `上传账号`、`上传账号状态` |
| 运维报告 | `用量日报`、`账号状态`、`失效账号`、`更新状态`、`运维日报` |
| 保存偏好 | `记住 绘图 中文坐标标签` |
| 查看/删除偏好 | `记忆列表`、`忘记 绘图` |
| 一次性计划 | `定时任务 2026-10-09 09:00 检查指定项目运行状态` |
| 每日计划 | `每日任务 09:00 检查指定项目运行状态` |
| 查看/取消计划 | `定时列表`、`取消定时 <计划编号>`、`定时帮助` |

设置只影响新任务，已排队任务保留原模型、推理等级和会话。编号选择窗口为 10 分钟；切换后仍可使用明确的“继续会话”指令。

偏好与计划命令由 Go 直接处理。偏好供后续任务参考，当前明确要求优先。计划使用北京时间，保存创建时的模型、推理强度及会话，到期按现有排队和并发规则执行并产生模型用量；任务执行不保证恰在指定秒开始。重启后计划保留，固定来源 ID 防止同一次执行重复入队。取消阻止后续入队，已经入队的任务继续执行。没有默认创建的用户计划。

不同会话可同时执行任务，默认最多 4 条；同一会话的普通消息按顺序排队。切换会话后发送任务即可并行处理，切换不会停止原会话；微信结果带原会话编号和任务编号。达到并发上限时，其他会话等待空位，正在等待你回答问题的任务也占一个执行位。

“补充：”只尝试加入当前选中会话的运行任务，只有收到 Codex 同一轮确认才标记为接受。带文件的补充进入下一轮；没有运行任务或轮次已结束时转为下一条任务。

上传链接有效期为 30 分钟。网页可以上传一个文件，也可以粘贴聊天并填写处理要求；显式提交后创建普通排队任务。获取链接、查看列表和账号导入不创建 AI 任务。

引用新消息时优先使用微信附带原文，否则按机器人/用户隔离的缓存恢复。旧消息未缓存、附件过期或微信只提供摘要时会明确说明，不编造引用原文。

任务页面展示本条问题摘要、过程文字、最终结果和文件；页面会自动刷新。微信接口拒收时，历史附件留在各自任务页，普通新消息不会自动恢复旧批次。

AI 需要选择或补充信息时，每个问题会单独发到微信，并显示选项编号。请**引用那条问题**后回复；回答会交回原任务，即使你已经切换会话也不会串任务。没有引用的普通消息继续排队，单独数字仍按会话选择规则处理。多个问题全部答完后继续；发送失败不会自动选择默认项。任务页也会显示待回答问题，发送“待回答”可重新查看。

等待回答计入任务总时限（部署默认 12 小时）。任务结束、超时或执行重试后，旧问题失效；引用旧问题会收到提示，不会创建新任务。不通过微信提问工具索取密码、API Key 或私钥。
