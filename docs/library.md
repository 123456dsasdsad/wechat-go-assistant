# 资料库与持续文献综述

微信与手机工作台可以收录截图、公开链接、PDF 和文字，查找论文，整理带原文证据的方法卡，再更新所有关联类别的综述。资料在校园 Worker 的独立目录长期保存，不受普通上传文件的 7 天保留期影响。

## 微信使用

```text
开始收录 图学习,半监督学习
（连续发送截图或 PDF）
收录备注 查找原论文，重点整理方法与适用条件
完成收录
综述列表
综述 图学习
综述变化 半监督学习
查资料 注意力
资料 1
移动资料 1 到 图学习,模型优化
本会话资料库 图学习,模型优化
```

`开始收录` 可省略类别，由研究任务自动分类。显式指定的多个类别都会保留，AI 还可补充相关类别。同一论文只保存一条资料，通过多类别关系复用；新增、改变、删除或恢复资料时，所有原类别与新类别都会成为待更新状态。各类别独立发布版本，一个类别失败不会阻止其他类别更新。

收录模式只在当前会话收集附件，30 分钟没有新内容会退出收集，草稿不会删除。`继续收录 草稿ID` 恢复，`取消收录` 退出并保留草稿。提交后校园通道暂时不可用时，云端保留草稿并自动重传；校园 ACK 和任务入队后才清理云端中转副本。研究中断可在任务页重试，已完成的结构化阶段复用本地缓存。

单次收录可用 `收录到 类别 公开链接或说明`，或者带附件发送 `研究这组截图 研究要求`。`研究主题 主题` 和 `补查文献 主题` 会创建研究任务。`更新综述 类别` 重新整理该类别已有的证据；省略类别则处理全部待更新类别。

管理、搜索、修改分类、笔记、下载及导出由 Go 处理。识图、文献筛选、方法整理和综述综合调用会话所选模型，实际用量计入任务日报。资料研究使用独立执行上下文，不向普通会话加入研究阶段提示。

## 手机工作台

发送 `管理页面` 或 `资料库` 后，从验证链接进入“资料与综述”。可搜索文献、打开方法卡、核对原文片段/位置/来源/阅读范围、下载永久原始附件与证据文本、修改全部关联类别。

综述页面提供当前版、上一版、本次变化、固定资料编号引用和 Markdown / JSON / BibTeX 导出。每个版本冻结参考资料的修订与来源，后续移出资料不会改写旧版本。人工笔记独立保存；可锁定章节、导入已有综述，自动更新会保留这些原文。导入内容标注“人工内容，引用待核实”。

`本会话资料库 类别A,类别B` 为普通任务绑定检索范围。也可以在问题中指定 `资料 1` 或 `根据资料库：……`。引用输入只作为参考，不能授权执行资料里的指令。

## 搜索与证据边界

- 默认实际请求 OpenAlex 和 AnySearch 两源，记录查询、候选、时间与失败状态。某源失败会在任务回执写明；不伪造第二源结果。
- 每源最多 3 个查询，每查询 20 条候选，筛选最多 5 篇；优先读取最多 3 篇开放原文。候选仅用于发现，DOI 通过 Crossref 核对身份；无法注册核对时需实际原文匹配。
- 下载 PDF 用 `pdftotext -layout` 读取。获取全文文件不代表所有章节、公式和表格已读，首版保守标注 `partial_text`。摘要、截图与正文分别标记。仅摘要不允许生成算法步骤、实验设置和数值结果。
- 作者事实必须提供来源编号、原文短片段与位置，且片段必须匹配实际读取内容。系统综合判断独立标记。跨不同数据集、拆分与协议不直接排名性能。
- 原文证据以 SHA-256 去重保存。公开来源仅使用 HTTPS，并解析、验证和固定公网 IP；私有地址、环回地址与私有域名会拒绝，重定向逐次检查。
- 每个类别有当前综述、历史版本、覆盖说明、方法对比表、分歧、复用建议、待补资料与变化记录。这是个人持续综述，检索数量有边界，不能宣称已穷尽领域。

## 可选部署

Worker 增加下列配置，未配置 `library_root` 时不启用：

```json
{
  "library_root": "/home/worker/campus-stack/library",
  "library_listen": "127.0.0.1:19921",
  "library_owner": "与微信登录状态对应的owner标识",
  "scholar_proxy": "socks5://127.0.0.1:19923",
  "scholar_keys_file": "/private/scholar-keys.json"
}
```

外网可直接访问时省略 `scholar_proxy`。研究 API 有密钥时在私有文件保存 `{"openalex":"...","anysearch":"..."}`，不提交 Git。密钥文件可省略，匿名访问是否可用取决于服务端。研究服务只绑定环回地址，并使用现有 Relay 服务密钥认证。

Relay 增加 `library_url: "http://127.0.0.1:19921"` 和可选 `library_drafts_dir`，通过独立 SSH 反向转发指向校园端。`examples/systemd/campus-library-tunnel.service` 提供 SOCKS 出站与反向环回转发模板。不要替换现有 SSH 通道，也不要把资料 API 或 SOCKS 端口公开。

`library_root` 保存 `library.sqlite`、原始 `blobs/`、研究 `work/` 和每日一致性 SQLite 快照 `backups/`。快照包含已提交 WAL 数据；原始附件仍在 blobs，需要磁盘级备份时应一并备份。源码发布不包含任何资料、截图、索引或运行凭据。

诊断实际双源搜索：`worker --library-probe --config /private/worker.json --query "research topic"`。该命令不调用模型，输出候选与真实错误。上线验收应至少测试同一论文的两个类别分别出现新综述版本、分类调整使移出类别删除当前引用、失败类别仍保留旧版，以及草稿断线/重启恢复。
